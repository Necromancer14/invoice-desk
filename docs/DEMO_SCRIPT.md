# 90 second demo script (screen recording)

Record the live Space or `localhost:8000`. No voice needed; captions are fine.

1. **0:00** Sign in as Admin. Dashboard is empty. Say: "Invoices in any format, decisions out."
2. **0:08** Upload invoices → Load all 60. Switch to Runs; rows fill in and statuses appear.
3. **0:20** Dashboard: the strip shows approved, waiting for review, rejected. Point at "cleared without a person".
4. **0:30** Open a rejected run: the failed rule and the trace. "Every decision can be explained."
5. **0:40** Review queue: original on the left, fields on the right. Fix one field, press approve (key **a**).
6. **0:52** Rules: Add rule "Flag invoices over 20,000". Press **Check impact on past invoices**: "N past invoices would change". Save. Show it in the version history. Restore the previous version.
7. **1:12** Evaluation: run with built-in rules; show the table and the honest weak rows (images, unusual wording).
8. **1:22** Toggle dark theme, then Arabic (layout flips right to left). End on the dashboard.

Optional second clip: Settings → Google Gemini → paste a free key → Save and test connection → run an unusual-wording invoice and show it read correctly.
